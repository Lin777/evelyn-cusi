# Evelyn Cusi López - Portfolio & Landing Page

[![Live Demo](https://img.shields.io/badge/demo-visit--site-blue?style=for-the-badge&logo=githubpages)](https://lin777.github.io/evelyn-cusi/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This is the source code for my personal portfolio and landing page. It's designed to be a clean, bilingual (English/Spanish) showcase of my journey and projects as a Data Scientist and AI Engineer specializing in production-ready AI systems.

**Live site:** [https://lin777.github.io/evelyn-cusi/](https://lin777.github.io/evelyn-cusi/)

---

## ✨ Features

*   **Bilingual Presentation:** Content presented seamlessly in both English and Spanish to reflect a global professional background.
*   **Project Highlights:** A clear "Featured Impact" section that focuses on **results** (like "21% Accuracy Gain" or "300+ Users") rather than just technical details.
*   **Technical Expertise:** An organized "Expertise Stack" that categorizes skills into AI/ML, Engineering, and Platforms for easy reading.
*   **Professional Narrative:** A "Technical Story" section that outlines career progression with clear impact statements.
*   **Personal Touch:** A "Life Beyond the Code" section adds personality and balance.

## 🛠️ Built With

This is a static, lightweight site built with fundamental web technologies for speed and reliability:

*   **HTML5:** For semantic structure.
*   **CSS3:** For custom styling and layout.
*   **JavaScript:** Minimal JS for interactivity (if any).
*   **Font Awesome:** For clean, professional icons.
*   **Google Fonts:** For typography.

## 🎯 Purpose & Goals

This site serves two main purposes:

1.  **Professional Portfolio:** To effectively communicate my experience, skills, and the tangible value I've delivered in AI and Data Science roles to potential employers and collaborators.
2.  **Personal Project:** To maintain a simple, fast, and easily deployable personal site on GitHub Pages, showcasing clean front-end fundamentals.
